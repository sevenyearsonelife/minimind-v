  - 视觉 token 直接并入语言 token 序列（单塔/统一 Transformer）

**3. 预训练（大规模多模态对齐）**

- 使用多模态指令数据做监督微调（SFT）。

### 问题 2
用户：vlm的预训练任务是什么？  
助手：常见的 VLM 预训练任务（按主流类别归纳）：

- 图文自回归生成（Caption/对话式生成）：给定图像生成文本，或图文混合序列做 LM loss  
- 图文对比学习（ITC）：拉近匹配图文、拉远不匹配图文，用于检索与语义对齐  
- 图文匹配（ITM）：二分类判断图文是否匹配  
- 掩码语言建模（MLM）：在图像条件下预测被掩码的词  
- 掩码视觉建模（MIM/MAE）：在文本条件下重建被掩码的视觉 token  
- 细粒度对齐/定位（区域-短语对齐、指代消解、grounding）：可用区域级对比/匹配损失  
- 多任务混合（将上述任务按比例混合训练）

实际会根据模型结构（单塔/双塔/跨注意力）和数据条件选择组合与权重。
