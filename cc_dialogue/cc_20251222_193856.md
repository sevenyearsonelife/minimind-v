### 问题 2

助手：基于对代码库的深入分析，MiniMind-V的训练经历了**两个主要阶段**：

## **MiniMind-V 训练阶段分析**

### **阶段一：预训练阶段 (Pretraining)**

**目标**：学习图像-文本对齐，建立基础的视觉理解能力
- **训练脚本**：`train_pretrain_vlm.py`
- **数据集**：`pretrain_data.jsonl` + `pretrain_images`
- **训练策略**：
  - 仅训练 `vision_proj` 层和 LLM 的最后一层
  - 冻结其他所有参数 (`trainer_utils.py:62-65`)
  - 使用相对较高的学习率：`4e-4`
  - 训练4个epoch

**关键代码**：
```python
# Pretrain阶段：冻结除 vision_proj 外的所有参数
if freeze_llm:
    for name, param in model.named_parameters():
        if 'vision_proj' not in name:
            param.requires_grad = False
```

### **阶段二：监督微调阶段 (SFT - Supervised Fine-tuning)**

**目标**：学习对话格式，提升问答能力
- **训练脚本**：`train_sft_vlm.py`
- **数据集**：`sft_data.jsonl` + `sft_images` (包含300K指令数据)
- **训练策略**：
  - 全参数微调
  - 使用较小学习率：`1e-6`
  - 训练2个epoch
  - 基于预训练权重：`--from_weight pretrain_vlm`

---

**★ Insight ─────────────────────────────────────**
* 这种分阶段训练策略是VLM模型的标准做法：先学会"看图"，再学会"对话"
* 预训练阶段只训练投影层可以避免破坏LLM的语言能力，同时建立图像-文本关联
* SFT阶段的全参数微调让模型适应真实的问答场景，大幅提升实用性
`─────────────────────────────────────────────────`

### **可选的第三阶段：多图微调**

项目还提供了多图对话的微调数据集（`sft_data_multi.jsonl`），这是一个可选的扩展阶段，用于处理包含多张图像的复杂对话场景。

**训练流程总结**：
1. **基础LLM** → 2. **预训练VLM** → 3. **SFT微调** → 4. **(可选)多图微调**

这种渐进式的训练策略既保证了训练效率，又确保了模型性能，是资源受限场景下训练VLM的最优实践。
