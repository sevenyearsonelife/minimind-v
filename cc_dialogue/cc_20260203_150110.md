### **步骤4：生成Labels（标记需要计算loss的位置）**

**代码位置**: `lm_dataset.py` 第43-59行

```python
def generate_labels(self, input_ids):
    labels = [-100] * len(input_ids)  # 初始化全为-100（不计算loss）
    # 只有 assistant 回复部分的 labels 会被设为对应的 token_id
```

**核心逻辑**：
- 找到 `<s>assistant\n` 开始的位置
- 从该位置后到 `</s>\n` 结束，将 labels 设为对应的 input_ids

**数值示例**：
```python
input_ids = [1, 4312, 10, 34, ..., 2, 10, 1, 13221, 10, 图, 片, 中, ..., 2, 10, 0, 0]
             |<----- user部分 ----->|    |<-- assistant部分 -->|    |pad|

labels    = [-100, -100, ..., -100,     图, 片, 中, ..., 2, 10, -100, -100]
             |<-- 不计算loss --->|      |<-- 计算loss -->|     |不计算|
```

| 位置 | input_ids | labels | 说明 |
|------|-----------|--------|------|
| 0 | 1 (`<s>`) | -100 | user开头，忽略 |
| 1-200 | 34,... (`@@...`) | -100 | image tokens，忽略 |
| ... | user问题 | -100 | 用户输入，忽略 |
| N | assistant回复第1个token | 该token_id | **参与loss计算** |
| N+1 | assistant回复第2个token | 该token_id | **参与loss计算** |
| ... | ... | ... | ... |
| M | `</s>` | 2 | **参与loss计算** |
| M+1 | padding | -100 | 忽略 |

### **步骤7：Model Forward 计算Loss**

**代码位置**: `model_vlm.py` 第113-171行

这是最关键的一步，分为多个子步骤：

#### **7.1 文本Embedding**

```

hidden_states[0, 0, :5] = tensor([0.0234, -0.1567, 0.3421, -0.0892, 0.1234])
```

#### **7.2 图像编码 + 投影**
```python
# CLIP编码
vision_tensors = get_image_embeddings(pixel_values, vision_encoder)
# vision_tensors.shape: [4, 196, 768]  (去掉CLS token后的patch embeddings)

```

#### **7.3 图像嵌入替换@@符号**
```python
# 在hidden_states中找到196个@的位置，用vision_proj替换
# 替换前: hidden_states[0, 3:199, :] 是196个@的embedding

    hidden_states, present = layer(hidden_states, position_embeddings, ...)

```

#### **7.5 LM Head 生成Logits**

```

```

#### **7.6 Shift对齐 + CrossEntropy Loss**

**代码位置**: `model_vlm.py` 第164-167行

```python
shift_logits = logits[..., :-1, :].contiguous()   # [4, 1535, 6400]
shift_labels = labels[..., 1:].contiguous()       # [4, 1535]
loss = F.cross_entropy(shift_logits.view(-1, shift_logits.size(-1)), 
                       shift_labels.view(-1), 
                       ignore_index=-100)
```

**Shift对齐原理**：

| 位置 | logits预测的token | labels真实值 | 是否计算loss |
|------|-------------------|-------------|-------------|
| 0 | 预测位置1的token | -100 | ❌ |
| ... | ... | -100 | ❌ |
| N-1 | 预测assistant第1个token | assistant第1个token_id | ✅ |
| N | 预测assistant第2个token | assistant第2个token_id | ✅ |
| ... | ... | ... | ✅ |

**数值示例**：
```python
# 假设模型预测位置N的下一个token
logits[0, N, :] = tensor([..., 2.5, ..., 5.8, ...])  # 词表上的logits
# 假设正确token_id=123, 对应logit=5.8

# softmax后的概率
probs = softmax(logits[0, N, :])  # probs[123] = 0.7 (假设)

# cross entropy loss
loss_N = -log(probs[123]) = -log(0.7) ≈ 0.357

# 最终loss是所有有效位置的平均
loss = average([loss_N, loss_{N+1}, ...])  # ≈ 1.2 (示例)
```

### **关键点总结**

1. **图像占位符**：使用196个`@`符号，对应CLIP输出的196个patch（14×14）
2. **Labels设计**：只有assistant回复部分才参与loss计算，-100表示忽略
3. **Shift对齐**：logits left-shift 1与labels对齐进行next-token prediction
4. **多模态融合**：在embedding层将图像特征替换到`@`位置
